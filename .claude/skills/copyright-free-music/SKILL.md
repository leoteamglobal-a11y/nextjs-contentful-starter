# Copyright-Free Music & Legal Covers (for House producers)

Help the user source vocals, acapellas and stems they can **legally** use to
produce **house covers / remixes**, and explain the licensing path when they
want to use a song that is still under copyright.

## What this skill will NOT do

This skill never helps anyone *evade* copyright. Specifically, refuse and
redirect if the request is to:

- Strip, "remove", or defeat copyright on a copyrighted song.
- Beat content-ID / fingerprinting (e.g. pitch-shift, time-stretch, add
  noise, nightcore, layer tones) **so a copyrighted track won't get
  detected/claimed**.
- Rip acapellas/stems from commercial tracks for distribution.

Copyright is not something you "take off" a recording — it belongs to the
rights holders until it expires or is licensed. Trying to dodge detection is
still infringement; it just hides it. Always steer the user to the legal
options below instead.

## Step 1 — Figure out what they actually need

Ask (or infer) two things:

1. **Use case**: personal practice / DJ set only, or public release
   (streaming, YouTube, sale)? Distribution is where licensing matters.
2. **Source material**: do they want *any* good vocal, or *a specific
   copyrighted song*? This changes everything (see Step 3 vs Step 4).

## Step 2 — Sources for genuinely free vocals, acapellas & stems

These are safe to build on, **but always check the exact license per track**
(some require attribution, some forbid commercial use, some forbid
derivatives — a remix IS a derivative):

| Source | What you get | Notes |
|---|---|---|
| **YouTube Audio Library** | Tracks + SFX | Filter by "free to use"; some need attribution |
| **Pixabay Music** | Music, some vocals | Pixabay license, commercial OK, no attribution |
| **Free Music Archive (FMA)** | CC + public domain | Check each track's CC flavor |
| **ccMixter** | Acapellas & remix-ready stems | Built for remixing; CC — read the BY/SA/NC terms |
| **Splice / Loopcloud** (paid) | Royalty-free vocals & loops | Licensed for use in your productions |
| **Cymatics, Ghosthack, etc.** | Royalty-free vocal packs | One-time purchase, cleared for release |
| **Uppbeat / Epidemic / Artlist** (subscription) | Cleared music | Good for video; check remix rights |
| **Acapellas4U / community packs** | Acapellas | ⚠️ many are unlicensed rips — verify rights before release |

**Public domain** (copyright expired) is fully free, but note: a *recording*
can be copyrighted even when the *composition* is public domain. Re-record or
use a PD recording.

## Step 3 — Official remix stems (the pro move)

Many labels/artists release **official acapellas or stem packs** and run
**remix contests** that grant a license to remix. This is the cleanest way to
remix a known song legally:

- Label "remix competition" / "stems" releases (Beatport, label sites,
  Skio / LabelRadar / Metapop campaigns).
- Some artists post official acapellas explicitly "for you to remix."
- Read the contest/terms: they usually allow the remix but **retain rights**,
  so you may not be able to monetize independently.

## Step 4 — Legally covering / remixing a copyrighted song

If they insist on a specific copyrighted track for **release**, explain the
real path (don't pretend it's free):

- **Cover** (you re-record/re-sing it): you need a **mechanical license**.
  In the US, get it via the **MLC** or services like **Easy Song**,
  **Songfile/HFA**. Distributors like **DistroKid / TuneCore / Amuse** offer
  cover-song licensing add-ons.
- **Remix** (you use the original master/acapella): you need permission from
  **both** the master owner (label) and the publisher (songwriters). There's
  no compulsory license for remixes — you must ask. This is why official stem
  packs (Step 3) exist.
- **Sync** (putting it in a video): needs a separate sync license.

## Step 5 — Platform reality check

- **YouTube / Instagram / TikTok**: Content ID will flag copyrighted audio
  even in a remix. A claim isn't a lawsuit, but it can mute, block, or divert
  monetization to the rights holder. Use cleared audio (Steps 2–3) to avoid it.
- **Spotify / Apple**: distributors require cover/remix licensing before they
  accept the upload.

## Step 6 — Where to actually GET acapellas (sorted by release-safety)

**🟢 Safe to RELEASE (royalty-free / CC-BY, cleared for commercial):**
- Free Vocals (freevocals.com) — studio acapellas, cleared for streaming
- ccMixter (ccmixter.org) — CC acapellas/stems built for remixing (check BY/NC)
- Looperman → Creative Commons & Remix-Stems tags
- Ghosthack — free royalty-free vocal packs
- Splice / Loopcloud (paid) — toplines & acapellas by BPM/key, fully licensed

**🟡 Mixed catalogs — verify each track's license before release:**
- Voclr.it, Acapellas4U, Looperman (general), SongStems.net, Acapellas.eu

**🔴 Do NOT release (infringement even when "free"):**
- User-uploaded Top-40 / famous-song acapellas = unlicensed rips → personal/DJ
  practice only
- Vocals extracted from a copyrighted track via LALAL.ai / UVR / Spleeter →
  legal tool, but releasing the remix needs label + publisher permission
- "Stems Master Pack" of famous artists on community sites = usually unofficial

## Step 7 — Famous tracks you CAN remix legally (right now)

The only legit way to remix a *known* song: official stems via a remix contest,
or public-domain classics. Contest sites block scrapers and change daily — the
user must open them live:

- RemiEXS (remiexs.com/remixcontest) — aggregator of nearly all open contests
- Skio Music (skiomusic.com/contests/remix) — enter, download official stems
- LabelRadar (greenroom.beatport.com/labels/labelradar/remix) — house/EDM labels
- Beatportal Remix Contests; EDMProd's "11 places" list
- Public domain: Musopen, awesome-cc0 — expired-copyright classics, fully free

## How to respond

1. Identify use case + whether they want a specific copyrighted song.
2. If free vocals are fine → point to Step 2/3 sources and remind them to
   check each license (attribution? commercial? derivatives allowed?).
3. If they want a specific copyrighted song → explain Step 3 (best) and
   Step 4 (licensing), not evasion.
4. Offer concrete next steps: search the free sources, pick a vocal with a
   compatible license, build the house production around it.
