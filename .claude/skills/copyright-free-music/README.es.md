# Skill: copyright-free-music 🎧

Skill para **producir covers y remixes house de forma legal**.

## Qué hace

Te ayuda a encontrar **vocales, acapellas y stems que SÍ puedes usar** y te
explica cómo licenciar un tema con copyright si quieres lanzarlo. No sirve
para "quitar copyright" ni para esquivar la detección de YouTube/TikTok
(eso sigue siendo infracción, solo que oculta).

## Cómo activarlo

Escribe `/copyright-free-music` o pídele a Claude cosas como:

- "Necesito acapellas libres para un remix house"
- "¿Qué vocales puedo usar legalmente en YouTube?"
- "Quiero hacer un cover, ¿cómo lo licencio para Spotify?"

## Las 3 rutas legales para tu cover/remix

1. **Vocales libres de derechos** (royalty-free / Creative Commons /
   dominio público) → revisa SIEMPRE la licencia de cada track:
   - YouTube Audio Library, Pixabay Music, Free Music Archive, ccMixter
   - Packs de pago ya licenciados: Splice, Loopcloud, Cymatics
   - ⚠️ Ojo: "remix" cuenta como *obra derivada*; algunas licencias CC
     (las **ND**) la prohíben, y las **NC** prohíben uso comercial.

2. **Stems oficiales / concursos de remix** (lo más pro): muchos sellos y
   artistas publican acapellas oficiales o lanzan *remix contests* que te
   dan permiso para remezclar un tema conocido.

3. **Licenciar un tema con copyright** si lo quieres lanzar:
   - **Cover** (lo regrabas) → licencia mecánica (MLC, Easy Song, o el
     add-on de cover de DistroKid/TuneCore).
   - **Remix** (usas el master/acapella original) → necesitas permiso del
     sello **y** del editor. No hay licencia automática: hay que pedirlo.

## Realidad de plataformas

Content ID detecta el audio con copyright **aunque lo remezcles o le cambies
el pitch/tempo**. Para evitar claims, usa audio ya autorizado (rutas 1 y 2).
