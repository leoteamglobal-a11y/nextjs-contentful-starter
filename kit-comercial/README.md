# Kit comercial — CasaHost

Material de negocio para arrancar tu operación de **co-hosting de Airbnb** (administrar
propiedades de otros a cambio de una comisión, sin comprar inmuebles).

Complementa el sistema web del proyecto:

- **Landing** (sitio público premium) → `/casahost.html`
- **Panel / CRM** para gestionar el negocio → `/airbnb/panel`

## Archivos

| Archivo | Para qué sirve |
|---|---|
| `Contrato-Administracion-CasaHost.docx` | Contrato de administración para firmar con cada dueño. Plantilla editable; revísala con un abogado antes de usarla. |
| `Propuesta-Comercial-CasaHost.docx` | Propuesta que envías a un dueño interesado (servicio, planes y proyección). |
| `Pitch-Deck-CasaHost.pptx` | Presentación de 10 diapositivas para vender el servicio o presentar el negocio a socios. |
| `Seguimiento-Ingresos-CasaHost.xlsx` | Hoja de cálculo con fórmulas: registra propiedades y reservas, y calcula tus comisiones automáticamente. |
| `calculadora.html` | Calculadora interactiva para propietarios. Publicada como Artifact para compartir por link/WhatsApp. |
| `estudio-mercado.html` | Estudio de mercado bilingüe (EN/ES) de Miami-Dade y Broward: demanda, zonas, competencia, regulación por ciudad, posicionamiento y proyección. Publicado como Artifact. |

## Notas

- Los importes de las plantillas son **ejemplos ilustrativos**; ajústalos a tu mercado.
- El Excel usa `fullCalcOnLoad`: al abrirlo en Excel o LibreOffice recalcula solo todas las fórmulas.
- Las cifras de proyección asumen ~$80/noche y 65% de ocupación; cámbialas por las de tu ciudad.
